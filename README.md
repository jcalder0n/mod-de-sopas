No se usar github y este es el primer mod que hago, la idea era aprender haciendo algo.

Mod simple que añade la posibilidad de hacer sopas en un caldero, requiere una fuente de calor (fogatas) debajo del caldero, luego puedes añadir los ingredientes de las 3 sopas/estofados basico:

sopa de hongos
sopa de remolacha
sopa de conejo

Para la sopa de hongos serán 3 hongos rojos y 3 marrones.

Para la sopa de remolacha serán 6 remolachas.

Para la sopa de conejo serán una zanahoria, una patata (cruda o cocida), un hongo marron o rojo y un conejo (crudo o cocido)

Todas dan 6 raciones de sopa haciendolas más eficientes ya que no vale la pena comerlas siendo que los ingredientes por separados son más nutritivos y sin contar que los tazones de sopa ocupan valioso inventario.

El caldero pierde la sopa si se rompe o se consumen las 6 porciones, solo acepta ingredientes válidos y confundir algun ingrediente no hará fallar la receta, se creará la primera cuyos ingredientes se cumplan primero.
